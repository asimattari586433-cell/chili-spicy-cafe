# Chili Spicy Cafe Website

A responsive static multi-page website built with HTML, CSS and vanilla JavaScript.

## Pages
- `index.html` — Home
- `menu.html` — Digital menu with category filters
- `about.html` — About the café
- `gallery.html` — Responsive photo gallery
- `contact.html` — Contact details, map preview and demo form

## Run locally
Open `index.html` in a browser, or run a local server from this folder:
- Python: `python -m http.server 8000`
- Then open `http://localhost:8000`

## Before handing over to the client
1. Replace all sample menu items and prices with the real menu.
2. Add the real street address, phone number, email and confirmed opening hours.
3. Replace stock photos with café-approved photography where available.
4. Connect the contact form to a backend or form provider; currently it is a front-end demo and does not send messages.
5. Connect an ordering/payment platform if online ordering is required.
6. Review accessibility, SEO, image licensing and performance before launch.

## Assets and external dependencies
- `assets/logo.png` is based on the logo image supplied for this project.
- Food and café photos are loaded from Unsplash URLs and require an internet connection.
- Google Maps iframe is a generic placeholder, not the café's confirmed location.
